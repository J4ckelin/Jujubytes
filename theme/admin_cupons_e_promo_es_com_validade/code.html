Motor Automatizado de Preço & Trigger Supabase

O marketplace Jujubyte garante consistência entre o catálogo e o checkout através da stored function PostgreSQL price_with_promotion(products). O cálculo de desconto prioritário avalia se há oferta pontual do produto antes de herdar a regra da categoria mãe.

public.price_with_promotion.sql
PL/pgSQL 
CREATE OR REPLACE FUNCTION price_with_promotion(p products)
RETURNS numeric AS $$
-- Busca promoção de maior impacto em vigor
SELECT round(p.price * (1 - (
  SELECT COALESCE(MAX(pr.discount_percent), 0) / 100.0
  FROM promotions pr
  WHERE pr.active = true 
    AND CURRENT_TIMESTAMP BETWEEN pr.start_at AND pr.expires_at
    AND (pr.product_id = p.id OR pr.category_id = p.category_id)
)), 2);
$$ LANGUAGE sql STABLE;
